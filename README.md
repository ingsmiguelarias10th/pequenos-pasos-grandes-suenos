# Pequeños pasos, grandes sueños

Galería virtual en 3D sobre nuestras visitas a la Fundación Niños de Paz (Floridablanca).

- Seis salas conectadas por puertas: la entrada y una sala por cada visita.
- Se recorre caminando (control en pantalla, WASD o flechas) o desde el menú "Salas".
- Al tocar una foto o un texto la cámara se acerca y se puede seguir el recorrido con "Anterior" y "Siguiente".

Hecha con [three.js](https://threejs.org/). Es una página estática: basta con abrir `index.html` desde un servidor o activar GitHub Pages en este repositorio.
